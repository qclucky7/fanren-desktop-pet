# 凡人修仙传桌宠 v0.1.0

首个公开版本，提供完整的 Windows 本地桌面宠物体验。角色资源、对话和用户设置均保存在本机，不依赖账号或网络服务。

## 版本亮点

- 内置多位《凡人修仙传》角色，可直接切换为桌面宠物。
- 支持待机动画、触摸反馈、拖动、鼠标视线跟随和随机对话。
- 提供独立的角色对话编辑、恢复默认和对话间隔设置。
- 通过系统托盘快速显示或隐藏宠物、打开管理界面及设置开机自启。

## 宠物与配置

- 宠物列表自动读取内置资源，无需维护固定角色清单。
- 每只宠物分别保存待机、拖拽和触摸对话，不会互相覆盖。
- 记住宠物上次拖动的位置；显示器环境变化时会自动恢复到可见区域。
- 支持从本地宠物目录添加符合 Codex Pet v2 图集契约的角色包。

## 界面体验

- 宠物管理页完整展示角色全身，并提供快捷的“设为桌宠”操作。
- 设置页支持跟随系统的明暗主题。
- 操作结果使用短暂消息提示，切换页面后不会残留。

## 下载与安装

- Windows 10/11 x64：下载 `凡人修仙传桌宠_0.1.0_x64-setup.exe` 并运行。
- 安装后可通过系统托盘管理桌宠；关闭管理窗口不会退出应用。

## 兼容性说明

- 当前正式发布仅提供 Windows x64 NSIS 安装包。
- 后续覆盖安装会保留用户的宠物设置、对话内容和窗口位置。
