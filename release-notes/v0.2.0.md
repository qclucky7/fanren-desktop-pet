# 凡人修仙传桌宠 v0.2.0

首个 GitHub Release。将《凡人修仙传》角色作为独立桌宠运行，在本机管理角色、对话和显示位置，无需账号或在线服务。

## 版本亮点

- 内置角色可在管理页预览全身并一键设为桌宠；现在也能从托盘“宠物列表”快速切换。
- 支持待机、触摸、拖动、鼠标视线跟随与随机对话。各角色的对话可独立编辑和恢复默认。
- 设置页可跟随系统外观，或手动选择浅色、深色主题；“关于”区域显示当前版本并提供更新与项目动态入口。

## 新增与改进

- 关闭管理窗口后应用继续留在托盘，可通过托盘显示或隐藏宠物、打开管理页、切换角色和退出。
- 可设置开机后静默启动至托盘；宠物位置会在拖动后记住。
- 调整管理页和设置页的视觉样式，并让窗口背景跟随主题切换。
- Windows 安装包的发布者信息显示为 `qclucky7 (GitHub)`。

## 问题修复

- 修复桌面端可能拒绝读取应用数据目录下宠物图集的问题。

## 下载与安装

- Windows x64：下载本 Release 附件中的 `fanren-desktop-pet_0.2.0_x64-setup.exe` 并运行。
- 安装后可从托盘打开宠物管理页。当前没有应用内自动更新；后续版本仍在 [GitHub Releases](https://github.com/qclucky7/fanren-desktop-pet/releases) 下载。

## 兼容性说明

- 这是首个 GitHub Release，无需迁移旧版数据。后续覆盖安装会保留应用数据目录中的用户设置和对话。
- 当前正式发布仅提供 Windows 安装包；未提供 macOS 或 Linux 构建。
