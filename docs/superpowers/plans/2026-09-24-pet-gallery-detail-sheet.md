# 宠物画廊与配置抽屉实施计划

**目标：** 在普通窗口尺寸下完整展示宠物列表，并将低频、纵向较长的配置内容放入右侧抽屉，避免列表与详情长期争抢宽度。

**设计：** 宠物页使用全宽响应式卡片画廊。点击卡片后，由页面维护选中项与抽屉开关，使用 shadcn/ui Sheet 从右侧呈现现有 `PetInspector`。列表与详情分别滚动，详情关闭后保留当前选择。

**技术栈：** React、TypeScript、shadcn/ui、Radix Dialog、Vitest、Tauri 2。

## 任务 1：引入标准 Sheet 基础组件

- 使用项目现有 shadcn 配置添加 `src/components/ui/sheet.tsx`。
- 检查并清理 CLI 可能产生的错误别名目录。
- 保持遮罩、焦点锁定、Escape 关闭和无障碍标题。

## 任务 2：把详情改造成受控抽屉

- 新增 `src/components/settings/PetDetailSheet.tsx`，只负责抽屉容器与详情组件装配。
- `PetManagementPage` 管理抽屉打开状态；点击宠物卡片时选择并打开，卸载成功后关闭。
- 保留现有保存、恢复、启用和卸载逻辑及数据契约。

## 任务 3：把宠物列表改成全宽响应式画廊

- 调整 `PetLibrary` 标题说明，明确点击卡片可打开配置。
- 卡片改为紧凑纵向构图，减少重复状态文案，仅突出当前使用项。
- 使用 `auto-fill + minmax` 自动排布，普通 920×680 窗口可容纳全部当前宠物，较窄或未来数量增加时仍可独立滚动。
- 抽屉宽度限制在 540px，并保留详情内部独立滚动。

## 任务 4：测试与运行验证

- 更新布局测试，覆盖全宽画廊、完整精灵比例、抽屉宽度和独立滚动。
- 运行 `npm test` 与 `npm run build`。
- 使用 `npm run tauri:dev` 验证窗口启动、普通尺寸列表和抽屉交互，并在结束后确认 1420 端口释放。
